# A05: Multiplication comes first — solution

**Answer:** C < A < B

- A: `6+4*3` = **18**.
- B: `(6+4)*3` = **30**.
- C: `36/3+5` = **17**.

So the order is **C < A < B**.

**Watch out:** Compare the final values, not the numbers that look biggest in the expressions.
