# A07: Small gaps — solution

**Answer:** B < A < C

- A: `35/8` = **4.375**.
- B: `4.25` = **4.25**.
- C: `17/4+0.2` = **4.45**.

So the order is **B < A < C**.

**Watch out:** Compare the final values, not the numbers that look biggest in the expressions.
