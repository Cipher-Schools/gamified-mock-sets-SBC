# A11: Return through a crossing — solution

**Answer:** 13 moves, including the move off the board.

Follow this route:

`R2C1 → R2C2 → R2C3 → R2C4 → R2C5 → R3C5 → R4C5 → R4C4 → R4C3 → R4C2 → R3C2 → R2C2 → R1C2 → outside`

There are 13 cell-to-cell moves. The last one leaves the board.

**Watch out:** Returning to a cell is only a loop if the direction is also the same.
