# A06: Four bubbles — solution

**Answer:** B < C < A < D

- A: `7*9-4` = **59**.
- B: `96/2+8` = **56**.
- C: `8*8-6` = **58**.
- D: `180/3` = **60**.

So the order is **B < C < A < D**.

**Watch out:** Compare the final values, not the numbers that look biggest in the expressions.
