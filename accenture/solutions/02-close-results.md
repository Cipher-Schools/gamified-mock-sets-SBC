# A02: Close results — solution

**Answer:** A < C < B

- A: `7*8` = **56**.
- B: `120/2` = **60**.
- C: `91-33` = **58**.

So the order is **A < C < B**.

**Watch out:** Compare the final values, not the numbers that look biggest in the expressions.
