# A05: Multiplication comes first

**Type:** Bubble arithmetic  
**Level:** Medium  
**Practice time:** 15–25 seconds (a practice target, not an official limit)

Work out each bubble. Write its letter in order, from the smallest result to the largest. Use normal arithmetic rules: brackets first, then multiplication and division, then addition and subtraction.

| Bubble | Expression |
|---|---|
| A | `6+4×3` |
| B | `(6+4)×3` |
| C | `36÷3+5` |
