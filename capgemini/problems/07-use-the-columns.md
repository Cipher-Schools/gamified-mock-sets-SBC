# C07: Use the columns

**Type:** Deductive symbol grid  
**Level:** Medium  
**Practice time:** 1–2 minutes (a practice target, not an official limit)

Each row and each column must contain **A, B, C, D** exactly once. A dot is a missing symbol. Fill every dot. There is **no smaller-box rule**.

```text
    1 2 3 4
 1  A . C D
 2  B C . .
 3  C . A B
 4  . A B C
```

Write your answer before opening the solution.
