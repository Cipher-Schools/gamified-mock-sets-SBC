# C06: Fill a small grid

**Type:** Deductive symbol grid  
**Level:** Easy  
**Practice time:** 1–2 minutes (a practice target, not an official limit)

Each row and each column must contain **A, B, C** exactly once. A dot is a missing symbol. Fill every dot. There is **no smaller-box rule**.

```text
    1 2 3
 1  A . C
 2  . C A
 3  C A .
```

Write your answer before opening the solution.
