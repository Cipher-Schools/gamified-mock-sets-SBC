# C04: Hold five positions

**Type:** Grid memory  
**Level:** Medium  
**Practice time:** 30–60 seconds (a practice target, not an official limit)

This is a paper version of a memory game. Use a **4 × 4** grid. Rows go top to bottom; columns go left to right.

1. Open each flash below in order. Look for 2 seconds, then close it before opening the next one. Do not write the positions down.
2. Keep all flashes closed while answering the picture question.
3. Write the flashed positions in the order you saw them. Include any repeated position.
