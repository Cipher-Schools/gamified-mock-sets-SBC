# C13: One extra mark — solution

**Answer:** Rule 2; options A and C.

The rule is: **The bottom row has one more X than the top row.**

- **A: yes**, because the top has 2 X marks and the bottom has 3.
- **B: no**, because the top has 0 X marks and the bottom has 2.
- **C: yes**, because the top has 1 X marks and the bottom has 2.
- **D: no**, because the top has 2 X marks and the bottom has 1.


**Watch out:** A rule must fit both examples. Then test every option against that same rule.
