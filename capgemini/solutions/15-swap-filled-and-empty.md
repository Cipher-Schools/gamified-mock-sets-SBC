# C15: Swap filled and empty — solution

**Answer:** Rule 3; options A and C.

The rule is: **The bottom row changes each X to a dot and each dot to X.**

- **A: yes**, because the required bottom row is `.XX.`, and the given row is `.XX.`.
- **B: no**, because the required bottom row is `..XX`, and the given row is `XX..`.
- **C: yes**, because the required bottom row is `XXXX`, and the given row is `XXXX`.
- **D: no**, because the required bottom row is `X..X`, and the given row is `.XX.`.


**Watch out:** A rule must fit both examples. Then test every option against that same rule.
