# C11: Find matching rows — solution

**Answer:** Rule 1; options A and C.

The rule is: **The two rows are identical.**

- **A: yes**, because the required bottom row is `.XX.`, and the given row is `.XX.`.
- **B: no**, because the required bottom row is `XX..`, and the given row is `..XX`.
- **C: yes**, because the required bottom row is `X..X`, and the given row is `X..X`.
- **D: no**, because the required bottom row is `XXXX`, and the given row is `....`.


**Watch out:** A rule must fit both examples. Then test every option against that same rule.
