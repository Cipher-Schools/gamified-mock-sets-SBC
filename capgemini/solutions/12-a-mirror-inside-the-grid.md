# C12: A mirror inside the grid — solution

**Answer:** Rule 3; options B and D.

The rule is: **Each row reads the same from left to right and right to left.**

- **A: no**, because at least one row changes when read in reverse.
- **B: yes**, because both rows read the same in reverse.
- **C: no**, because at least one row changes when read in reverse.
- **D: yes**, because both rows read the same in reverse.


**Watch out:** A rule must fit both examples. Then test every option against that same rule.
