# C06: Fill a small grid — solution

**Answer:** The completed grid is:

```text
    1 2 3
 1  A B C
 2  B C A
 3  C A B
```

1. R1C2 must be **B**: the other symbols already appear in its row or column.
2. R2C1 must be **B**: the other symbols already appear in its row or column.
3. R3C3 must be **B**: the other symbols already appear in its row or column.

Check the finished grid: every row and column has each symbol once.

**Watch out:** These are row-and-column puzzles. Do not add Sudoku box rules.
