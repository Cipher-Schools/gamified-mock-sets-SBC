# C14: Shift to the right — solution

**Answer:** Rule 1; options B and D.

The rule is: **Shift the top row one place right, wrapping the last cell to the front.**

- **A: no**, because the required bottom row is `.X..`, and the given row is `..X.`.
- **B: yes**, because the required bottom row is `.X.X`, and the given row is `.X.X`.
- **C: no**, because the required bottom row is `..XX`, and the given row is `XX..`.
- **D: yes**, because the required bottom row is `X..X`, and the given row is `X..X`.


**Watch out:** A rule must fit both examples. Then test every option against that same rule.
